# GitHub Pages Pixi-bog m. Lisbeth (tors 20. aug kl.12-13.30)

Formål: indføring i at bygge Git-Pages, hands-on intro så jeg kan bygge min egen når jeg skal præsentere mine resultater for jer.

Spørgsmål: 
Kategori 1: brug af Github pages som værktøj 
- Hvad er Github pages ( kort intro)
- Hvordan og til hvad anvender du Github pages?
- Hvorfor er det godt at bruge github pages ?
- Hvad er svært ved at bruge Github pages
- Er der noget man skal huske ?

Kategori 2. Pixibogen som koncept
- Hvad er Pixibgen og hvordan skal den anvendes i praksis ?
- Hvornår, hvordan og hvorfor opstod er Ideen bag udviklingen af Pixibogen ?
- Hvordan har du grebet det an / hvordan var din proces?
- Hvad er strategien for udbredelse, udruldning og lifecycle management af Pixibogen?
- Hvordan får man det til at ligne en "rigtig" website og ikke en Github udvidelse ( skift af URL)?

Kategori 3: Hands- on session
- Hvordan kommer jeg igang ?
- Hvad er princippet for at en side vises/ ikke vises ?
- Hvor kan jeg finde hjælp og viden til at/ hvilke ressourcer vil du pege mig hen mod?
- Hvordan ændrer jeg i layuout og funktionalitet
- Hvordan Contributer jeg tilbage
- Hvordan skifter jeg URL på min Github pages i praksis (i OS2 regi)?
- Kan jeg ændre et repository til at blive github pages understøttende eller skal jeg starte helt forfra og flytte mine sider?
